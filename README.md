# smart-monsoon-electrical-safety-system
Embedded safety system for detecting environmental and electrical hazards during waterlogging conditions.
## Project Status

Simulation Prototype / Work in Progress

## Objective

To develop an embedded safety system that monitors environmental conditions during waterlogging and identifies potential electrical hazards.

## Current Prototype

The current prototype simulates:
- Water level
- Rain intensity
- Electrical hazard indicator

The system classifies the condition as:
- SAFE
- CAUTION
- DANGER

## Future Hardware Implementation

- ESP32 / STM32 microcontroller
- Water-level sensor
- Rain sensor
- Isolated low-voltage hazard sensing
- OLED display
- Buzzer and warning LEDs
- Wireless alert system
